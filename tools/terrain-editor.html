Road tool

Click: add waypoint (starts a new road if none is being drawn). Drag point: move. Click on a line: insert point. Delete: remove selected point. Enter / double-click: finish road. Pick roads in the list; "Continue" appends to the selected road. Per-point Bridge checkbox: the segment from that point to the next is a bridge (dashed, not baked).

Hints

Hardness 1 = hard cliff/plateau edges, hardness 0 = soft rolling hills. Holding the mouse still keeps applying the brush. Flatten samples height at stroke start unless a typed target is enabled. Water tool: click on the terrain height you want as lake level, drag to carve a lake there. Autosave to the browser runs ~10 s after changes.
